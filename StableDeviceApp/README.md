# 器件管理系统

## 概述

器件管理系统是一款基于 **React Native + Expo** 开发的移动应用，用于管理电子器件库存和 BOM 配单。系统支持多库存（器件架）管理，每个库存可独立绑定蓝牙模块，并通过蓝牙向下位机发送指令，控制器件架上的指示灯，方便器件的请求和取出操作。应用以管理员身份自动登录，无需手动登录注册。

## 应用功能

### 1. 多库存管理

- **新装零库存**：新下载的应用不预置任何库存，需用户自行新建
- **新建库存**：在"设置 → 库存管理"中可创建多个独立库存（器件架），每个库存有独立名称、器件列表与蓝牙绑定
- **重命名库存**：长按或点击编辑按钮修改库存名称
- **删除库存**：删除不需要的库存（连同其下所有器件）
- **库存间切换**：在库存首页底栏"切换库存"面板中快速切换
- **蓝牙绑定徽章**：库存管理列表中显示每个库存是否已绑定蓝牙及蓝牙名称
- **空状态保护**：零库存时 4 个 tab 全部常驻可点; "连接"和"BOM匹配"两页顶部出现 ⚠️ 黄色提示条, 用户点击"扫描蓝牙设备"或"导入 BOM"时弹"当前无库存"提示, 不执行动作, 引导用户去"设置"新建/导入库存

### 2. 器件管理

- **器件库存**：查看当前库存下所有器件的详细信息，包括名称、功能、类别、封装、位置、备注等
- **器件搜索**：支持按名称、功能、编号等多种方式搜索器件
- **器件筛选**：按器件架（A/B/C/D）筛选器件
- **器件详情**：查看器件的详细信息
- **器件上架**：添加新器件到当前库存
- **器件编辑**：编辑现有器件信息
- **器件删除**：删除不需要的器件
- **批量导入**：支持从 Excel/CSV 文件批量导入器件数据
- **扫码导入**：扫描条码导入器件，确认后直接上架到第一个空位置，也可选择指定位置

### 3. BOM 配单

- **导入 BOM**：从 Excel/CSV 文件导入 BOM 配单，自动识别器件
- **加载 BOM**：加载已保存的 BOM 配单
- **删除 BOM**：删除不需要的 BOM 配单
- **器件状态显示**：自动识别 BOM 中的器件，库存充足显示为绿色，库存不足显示为橙色
- **器件请求**：点击绿色器件时，通过蓝牙发送指令到下位机，控制对应位置的灯亮起

### 4. 器件请求与取出

- **请求器件**：发送指令点亮对应位置的指示灯
- **取出器件**：发送指令熄灭对应位置的指示灯（仅库存充足时可操作）
- **控制所有灯**：支持一键点亮或熄灭所有指示灯

### 5. 数据管理

- **数据导出**：将指定库存导出为 JSON 文件，**文件名 = 库存名**（如 `库存A.json`），支持自定义保存位置
- **应用内导入**：在"个人中心"选择 JSON 文件导入
- **外部应用导入**：从微信、QQ、邮件等外部 App 打开或分享本应用时，自动识别 JSON 文件并提示导入
- **按文件名判断**：导入时以文件名为目标库存名
  - 本地有同名库存 → **覆盖**该库存的器件，保留其 id 与蓝牙绑定
  - 本地无同名库存 → **新增**为新库存，并沿用导入文件中该库存的蓝牙绑定
- **导入后自动切库**：导入完成自动切换到该库存为当前库存
- **不影响其他数据**：导入仅修改匹配库存的器件，不动分类、用户、其他库存

### 6. 蓝牙连接

- **蓝牙连接**：连接到蓝牙设备（如 CH9140），搜索并配对蓝牙模块
- **多波特率自适应**：自动检测蓝牙模块的 UART 波特率，支持 **9600**（出厂默认）与 **115200**（AT+BAUD8 切到）
- **库存自动绑定蓝牙**：在某个库存下成功连接蓝牙后，该 MAC 自动绑定为该库存的匹配蓝牙
- **切库自动重连**：切换到已绑定蓝牙的库存时，自动重新连接该 MAC
- **切库断开未绑定库存**：切换到未绑定蓝牙的库存时，自动断开当前连接
- **导入后自动连接**：从外部导入库存后，后台自动尝试连接该库存绑定的蓝牙
- **不在范围提示**：5 秒内未扫到目标蓝牙时，弹出"蓝牙不在范围"提示，可一键跳到连接页手动扫描
- **连接状态徽章**：库存首页右上角实时显示当前蓝牙连接状态

## 使用方法

### 1. 快速开始

- 打开应用后自动以管理员身份登录，无需手动登录
- **首次使用需新建库存**：进入"设置 → 库存管理"，点击"+ 添加库存"创建第一个库存
- 所有功能均可直接使用

### 2. 库存管理

- **新建库存**：设置 → 库存管理 → 点击"+ 添加库存"，输入库存名后确认
- **重命名库存**：在库存管理列表点击库存右侧的编辑按钮
- **删除库存**：在库存管理列表点击库存右侧的删除按钮
- **查看蓝牙绑定**：列表中带"已绑定: <设备名>"标记的库存已关联蓝牙模块
- **切换当前库存**：在库存首页底部弹出的"切换库存"面板中选择

### 3. 器件管理

- **查看器件**：在"库存"标签页查看当前库存的所有器件
- **搜索器件**：在搜索框中输入关键词搜索器件
- **筛选器件**：点击器件架选择器筛选特定器件架的器件
- **上架器件**：点击"新建器件"按钮添加新器件
- **编辑器件**：点击器件卡片进入编辑页面修改器件信息
- **删除器件**：长按器件卡片或进入编辑页面后删除
- **批量导入**：在"新建器件"页面点击"从 Excel/CSV 导入"按钮导入器件数据
- **扫码导入**：点击扫码按钮扫描条码，确认后上架到空位置，也可点击位置按钮选择指定位置后再确认上架

### 4. BOM 配单

- **导入 BOM**：在"BOM 配单"标签页点击"导入 BOM 文件"按钮，选择 Excel 或 CSV 文件
- **加载 BOM**：点击"加载已保存的 BOM"按钮选择并加载已保存的 BOM
- **查看器件状态**：导入或加载 BOM 后，系统会自动识别器件状态
- **请求器件**：点击绿色器件时，系统会通过蓝牙发送指令到下位机
- **删除 BOM**：在 BOM 列表中点击"删除"按钮

### 5. 器件请求与取出

- **连接设备**：在"连接"标签页搜索并连接蓝牙设备，或让系统自动连接当前库存绑定的蓝牙
- **请求器件**：在器件详情页面点击"请求此器件"按钮
- **取出器件**：在器件详情页面点击"取出器件"按钮
- **控制所有灯**：在器件列表页面底部点击"点亮所有灯"或"熄灭所有灯"按钮

### 6. 数据管理

- **数据导出**：
  1. 在"个人中心"页面点击"数据导出"按钮
  2. 选择要导出的库存（可多选）
  3. 系统弹出保存界面，默认文件名为 `<库存名>.json`，可重命名
- **应用内导入**：
  1. 在"个人中心"页面点击"数据导入"按钮
  2. 选择 JSON 文件
  3. 按文件名匹配库存：同名覆盖、异名新增
- **外部导入**：
  1. 在微信、QQ、邮件等 App 中点击本应用导出的 JSON 文件
  2. 系统提示"导入数据"弹窗，确认后按文件名匹配库存
  3. 导入成功后弹窗提示"已新建库存 X"或"已覆盖库存 X"
  4. 自动切换到该库存并尝试连接其绑定的蓝牙
- **BOM 导入**（外部）：
  1. 在外部 App 中打开或分享 Excel/CSV BOM 文件
  2. 系统提示"导入 BOM"弹窗，确认后自动跳转到 BOM 配单界面

## 安装步骤

### 开发版

```bash
# 1. 克隆项目到本地
git clone https://github.com/pollllli/Bluetooth-device.git

# 2. 进入项目目录
cd StableDeviceApp

# 3. 安装依赖
npm install

# 4. 启动开发服务器
npm run android
```

1. 下载 `app-release.apk` 文件
2. 直接安装到 Android 设备上
3. 打开应用后，进入"设置 → 库存管理"新建第一个库存即可开始使用

## 通信协议

系统使用自定义串口协议与下位机通信，详见 `PROTOCOL.md` 文件。

### 命令帧格式

所有指令帧遵循以下格式（7 字节）：

```
[55] [AA] [CMD] [LEN] [DATA_H] [DATA_L] [CRC]
  ↑    ↑    ↑     ↑      ↑       ↑       ↑
帧头  帧头 命令字 数据长度 数据高字节 数据低字节 CRC-8/MAXIM
```

### 支持的命令

| 命令字 | 功能       | 数据格式                            |
| ------ | ---------- | ----------------------------------- |
| 0x00   | 心跳       | uint16_t (0x0001)                   |
| 0x01   | 点亮对应灯 | uint16_t (灯 ID 1-255)              |
| 0x02   | 熄灭对应灯 | uint16_t (灯 ID 1-255)              |
| 0x03   | 控制所有灯 | uint16_t (0xFFFF=点亮, 0x0000=熄灭) |

### 响应帧格式

响应帧命令字 = 发送命令字 + 0x80

| 命令字 | 响应命令字 |
| ------ | ---------- |
| 0x00   | 0x80       |
| 0x01   | 0x81       |
| 0x02   | 0x82       |
| 0x03   | 0x83       |

### 蓝牙模块 UART 波特率

应用支持以下两种蓝牙模块 UART 波特率（连接时自动按序尝试，**第一个心跳通过的即锁定**）：

| 波特率 | 适用场景                    | AT 指令设置 |
| ------ | --------------------------- | ----------- |
| 9600   | 出厂默认（CH9140 默认值）   | `AT+BAUD4`  |
| 115200 | 高速通信（用户可手动切换）   | `AT+BAUD8`  |

应用会在连接 BLE 后自动按 `9600 → 115200` 顺序发送 `AT+BAUD` + 心跳验证，无需用户手动配置。

## 常见问题

### Q1: 蓝牙连接失败怎么办？

1. 确保设备蓝牙已开启
2. 确保蓝牙设备已进入可发现模式
3. 检查设备是否在蓝牙范围内
4. 应用会自动检测波特率（9600/115200），如仍失败，确认蓝牙模块的 UART 波特率是否与 MCU 一致
5. 尝试重启应用后重新连接

### Q2: 灯不亮怎么办？

1. 检查蓝牙连接状态（库存首页右上角徽章）
2. 确认当前库存已绑定蓝牙模块（设置 → 库存管理查看徽章）
3. 确保器件位置配置正确
4. 检查下位机电源和接线
5. 尝试重新发送指令

### Q3: 数据丢失怎么办？

1. 使用"数据导入"功能从导出文件恢复（应用内或从外部 App 打开）
2. 建议定期使用"数据导出"功能备份数据到外部存储
3. 导出文件名即为库存名，按文件名即可恢复到对应库存
4. 确保应用正常退出，避免强制关闭

### Q4: 扫码导入如何使用？

1. 点击扫码按钮扫描器件条码
2. 扫码后弹出确认弹窗，默认上架到第一个空位置
3. 如需指定位置，点击位置按钮选择后再确认上架

### Q5: 切换库存时蓝牙会断开吗？

取决于目标库存是否已绑定蓝牙：

- **目标库存已绑定蓝牙**：自动尝试重新连接该 MAC
- **目标库存未绑定蓝牙**：断开当前连接，提示到"连接"页手动扫描连接
- 不会"自动继承"上一个库存的蓝牙绑定

### Q6: 多个库存可以共用同一个蓝牙模块吗？

可以。蓝牙 MAC 与库存是多对一关系（多个库存可绑定同一个 MAC）。但**同时**只能有一个库存是当前库存，蓝牙一次只能服务于一个库存。

### Q7: 微信分享的库存文件打不开？

1. 确认文件扩展名为 `.json`（本应用导出的格式）
2. 分享时选择"用其他应用打开"→ 选择本应用
3. 如反复失败，可先把文件保存到本地，再通过"个人中心 → 数据导入"选择

### v1.6.9 (2026-08-12)

**问题修复：**

- 修复扫码识别成功弹窗 → 位置选择器 → 取消后, 第一个空位置的灯熄灭的问题

- **BOM 失焦完整清理**：BOM 页面失焦时同步清 `litDeviceIds` + 走 store + 物理灭灯（推到 `setTimeout(0)` 异步执行）
