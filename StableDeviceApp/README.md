# 器件管理系统

## 概述

器件管理系统是一款基于 **React Native + Expo (SDK 55)** 开发的 Android 移动应用，用于管理电子器件库存和 BOM 配单。系统支持多库存（器件架）管理，每个库存可独立绑定蓝牙模块（CH9140），通过蓝牙向下位机发送 7 字节指令帧，控制器件架上的指示灯亮/灭，方便器件定位和取出。应用以管理员身份自动登录，无需注册。

## 应用功能

底部有 **4 个常驻 Tab**：库存、连接、BOM匹配、设置。

### 1. 多库存管理

- **新装零库存**：新安装的应用不预置任何库存，需用户自行新建
- **新建/重命名/删除库存**：在"设置 → 库存管理"中操作，删除会连同该库存下所有器件
- **库存间切换**：在库存首页底栏弹出的"切换库存"面板中快速切换
- **蓝牙绑定徽章**：库存管理列表中显示每个库存是否已绑定蓝牙及设备名称
- **空状态保护**：零库存时 4 个 tab 全部常驻可点；"连接"和"BOM匹配"两页顶部出现黄色提示条，点击操作按钮时弹"当前无库存"提示引导用户先建库存

### 2. 器件管理

- **器件列表**：在"库存"Tab 查看当前库存下所有器件，支持按名称/功能/编号搜索，按器件架（A/B/C/D）筛选
- **点击切换亮/灭灯**：直接点击器件卡片，未亮灯 → 点亮对应位置灯（绿底高亮）；已亮灯 → 熄灭
- **编辑器件**：在器件卡片上**左滑**（SwipeableRow）调出操作按钮，点击"编辑"进入编辑页
- **删除器件**：在器件卡片上**左滑**调出操作按钮，点击"删除"
- **新建器件**：点击"新建器件"按钮，支持手动填写或拍照/相册上传器件图片
- **批量导入**：从 Excel/CSV 文件批量导入器件数据
- **扫码导入**：点击扫码按钮扫描条码（支持 QR/EAN13/Code128 等），确认后自动上架到第一个空位置，也可在位置选择器中指定位置

### 3. BOM 配单

- **导入 BOM**：从 Excel/CSV 文件导入 BOM 配单，自动匹配器件
- **加载已保存的 BOM**：加载之前保存的 BOM
- **删除 BOM**：删除不需要的 BOM
- **器件状态颜色**：库存充足显示绿色，库存不足显示橙色
- **点击切换亮/灭灯**：点击绿色（已匹配）的 BOM 条目，切换该条目所有匹配器件的亮/灭灯状态
- **清空 BOM**：清空当前 BOM，同时熄灭所有灯
- **外部 BOM 导入**：从微信/QQ/文件管理器等外部 App 打开或分享 Excel/CSV BOM 文件，自动跳转到 BOM 页面并导入

### 4. 数据管理

- **数据导出**：在"设置"页点击"数据导出"，选择要导出的库存（可多选），导出为 JSON 文件，文件名 = 库存名
- **数据导入**：在"设置"页点击"数据导入"，选择 JSON 文件导入
- **外部 App 导入**：从微信/QQ/邮件等外部 App 打开或分享本应用导出的 JSON 文件时，自动识别并提示导入
- **导入规则**：以文件名为目标库存名，本地有同名库存 → 覆盖器件（保留蓝牙绑定）；本地无同名库存 → 新增库存
- **导入后自动切库 + 自动连蓝牙**：导入完成后自动切换到该库存，并尝试连接其绑定的蓝牙

### 5. 蓝牙连接

- **只扫描 `W02_` 前缀设备**：过滤掉其他蓝牙设备，只显示本 App 专用蓝牙模块
- **波特率固定 9600**：蓝牙模块 UART 波特率锁定使用 **9600**（CH9140 出厂默认值），连接后发送心跳验证
- **库存自动绑定蓝牙**：在某个库存下成功连接蓝牙后，该 MAC 自动绑定到该库存
- **切库自动重连/断开**：切换到已绑定蓝牙的库存时自动重连；切换到未绑定蓝牙的库存时断开当前连接
- **导入后自动连接**：从外部导入库存后，后台自动尝试连接该库存绑定的蓝牙（10 秒超时）
- **不在范围提示**：5 秒内扫不到目标蓝牙时弹出"蓝牙不在范围"提示
- **连接状态徽章**：库存页右上角实时显示蓝牙连接状态
- **一键控制所有灯**：在库存列表页面底部点击"点亮所有灯"或"熄灭所有灯"按钮（走快速通道，1.5 秒硬超时，BLE 链路挂起时不卡死）

## 使用方法

### 1. 快速开始

1. 安装 APK
2. 打开应用，自动以管理员身份登录
3. 进入"设置 → 库存管理"，点击"+ 添加库存"创建第一个库存
4. 进入"连接"Tab，扫描 `W02_` 蓝牙模块并连接
5. 进入"库存"Tab，开始添加器件

### 2. 亮灯/灭灯操作

- **库存页**：直接点击器件卡片切换亮/灭灯
- **BOM 页**：点击绿色（已匹配）的 BOM 条目切换亮/灭灯
- **所有灯**：库存页底部"点亮所有灯"/"熄灭所有灯"按钮
- **状态同步**：所有页面的亮灯状态通过 `lightStatusStore` 集中管理，任意页面亮/灭灯都会同步到其他页面

### 3. 编辑/删除器件

在器件卡片上**左滑**，出现"编辑"和"删除"按钮，点击对应操作。

### 4. 扫码导入

1. 在新建器件页面点击扫码按钮
2. 扫描条码后弹出确认弹窗，默认上架到第一个空位置
3. 如需指定位置，点击位置按钮打开位置选择器（自动点亮第一个空位置预览）
4. 确认后上架
5. v1.6.9：位置选择器取消时会自动重新点亮第一个空位置的灯

### 5. 数据导入/导出

- **导出**：设置 → 数据导出 → 勾选库存 → 导出为 `<库存名>.json`
- **应用内导入**：设置 → 数据导入 → 选择 JSON 文件
- **外部导入**：在微信/QQ/文件管理器中点击 JSON 文件 → 选择用本 App 打开 → 确认导入

### 6. 库存管理

- 设置 → 库存管理 → 新建/重命名/删除库存
- 库存首页底栏"切换库存"面板快速切换

## 通信协议

系统使用自定义串口协议与下位机通信，详见 [PROTOCOL.md](PROTOCOL.md)。

### 命令帧格式（7 字节）

```
[55] [AA] [CMD] [LEN] [DATA_H] [DATA_L] [CRC]
  ↑    ↑    ↑     ↑      ↑       ↑       ↑
帧头 帧头 命令字 数据长度 数据高字节 数据低字节 CRC-8/MAXIM
```

### 支持的命令

| 命令字 | 功能 | 数据格式 |
|---|---|---|
| 0x00 | 心跳 | uint16 (0x0001) |
| 0x01 | 点亮对应灯 | uint16 (灯 ID 1-255) |
| 0x02 | 熄灭对应灯 | uint16 (灯 ID 1-255) |
| 0x03 | 控制所有灯 | uint16 (0xFFFF=点亮, 0x0000=熄灭) |

### 响应帧

响应命令字 = 发送命令字 + 0x80（如 0x01 → 0x81）

### UART 波特率

应用锁定使用 **9600** 波特率（CH9140 出厂默认值），连接后自动发送心跳验证。确保蓝牙模块和下位机 MCU 的 UART 波特率都设置为 9600。

## 常见问题

### Q1: 蓝牙扫描不到设备？

本 App **只扫描 `W02_` 开头的蓝牙模块**，其他设备会被过滤。如果模块名称不是 `W02_` 前缀，需在厂商工具中改名，或修改源码中 `BluetoothHandler.js` 的过滤条件。

### Q2: 蓝牙连接失败？

1. 确保设备蓝牙已开启
2. 确保 `W02_` 蓝牙模块在范围内
3. 确认蓝牙模块 UART 波特率设置为 **9600**，且与 MCU 一致
4. 重启应用后重试

### Q3: 切换库存后旧库存的灯没灭？

已修复（v1.2.2）：走 `fastControlAll` 快速通道（1.5 秒硬超时，不等 ACK），即使 BLE 链路被 OS 挂起也能快速灭灯。

### Q4: 灯不亮？

1. 检查库存页右上角连接徽章（已连接/未连接）
2. 在"设置 → 库存管理"确认当前库存已绑定蓝牙
3. 确认器件位置配置正确
4. 检查下位机电源和接线
5. 尝试重新发送指令

### Q5: 数据丢失？

使用"设置 → 数据导入"从之前导出的 JSON 文件恢复。**建议定期使用"数据导出"功能备份数据**。

### Q6: 微信分享的 JSON 文件打不开？

1. 确认文件扩展名为 `.json`
2. 分享时选择"用其他应用打开"→ 选择本应用
3. 如反复失败，先保存到本地，再通过"设置 → 数据导入"选择文件

### Q7: 扫码后位置选择器取消了，为什么灯灭了？

v1.6.9 已修复：取消位置选择器时会自动重新点亮第一个空位置的灯。v1.6.8 及之前版本取消时灯会熄灭。
